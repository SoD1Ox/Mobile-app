# Flutter-клиент

Мобильный и веб-клиент для FastAPI-сервера кадрового агентства.

## Разделы приложения

- Вход и регистрация.
- Главная со статистикой и навигацией по ролям.
- Вакансии: поиск, фильтры, сортировка по зарплате и локальное избранное.
- Кандидаты, компании, контакты и заметки рекрутера.
- Канбан-воронка откликов с историей статусов.
- Управление пользователями для администратора.

## Запуск

```powershell
flutter pub get
flutter run -d edge
```

Компьютерный клиент подключается к `http://127.0.0.1:8000/api/v1`, Android-эмулятор — к `http://10.0.2.2:8000/api/v1`. Адрес можно переопределить через `--dart-define=API_BASE_URL=...`.

## APK

```powershell
flutter build apk --release --dart-define=API_BASE_URL=http://<IP-компьютера>:8000/api/v1
```

API должен быть запущен на компьютере и доступен телефону по Wi-Fi. Подробности находятся в [гайде проекта](../docs/GUIDE.md).
